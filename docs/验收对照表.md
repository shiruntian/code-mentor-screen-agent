> **测试版本（v1.0.0-beta）· AI 辅助开发 · 功能尚未完善**

| 项 | 做法 | 位置 |
| --- | --- | --- |
| **XML 工具调用兼容** | 识别 `<tool_call>` 纯文本格式并转为真调用；流式过滤保证答案里不出现标签 | `agent/xml_calls.py` |

| **中途提问** | `ask` 动作 → 会话 waiting → 界面输入/选项 → 答案注入上下文并续跑 | `controller._ask_user/answer` |

| **任务拆解** | `detect_multi_action` 系统兜底拆解 + `plan_tasks` 工具；本轮只做第一件 | `agent/tasks.py`、`agent/runtime.py` |
| **任务不丢** | `agent_tasks` 表持久化，每轮注入提示词；界面有任务清单折叠条 | `agent/tasks.py`、`components/TaskBar.vue` |
