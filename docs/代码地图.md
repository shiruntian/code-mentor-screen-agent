## 五、一条请求的完整路径

```
Composer.vue  (@click 发送)
  └→ stores/app.ts:378 send()
       └→ api/client.ts:66 streamSSE('/api/chat')
            └→ chat.py:21 POST /api/chat
                 └→ chat_service.py:85 stream_turn()
                      └→ agent/graph.py:534 run_graph()
                           ├ plan_node  (graph.py:129)
                           ├ act_node   (graph.py:189)
                           ├ tools_node (graph.py:286)  ← 工具/知识库/记忆/联网
                           └ answer_node(graph.py:405)
                      ← SSE 事件逐条 yield (chat_service.py:142)
       ← stores/app.ts:448 分发事件，更新 live / messages
  ← MessageList / MessageItem 渲染
```

## 六、想改某处时去哪

| 要做的事 | 改这里 |
| --- | --- |
| 加一个 Agent 工具 | 写 `@tool` 到 `agent/tools/*.py`，登记进 `runtime.py` 的工具目录 |
| 改流程拓扑（加节点/改条件边） | `agent/graph.py:521` 附近的装配段 |
| 加一个 REST 接口 | 新建 `api/routes/xxx.py`，在 `main.py:183` 附近注册 |
| 加一张表 | `db/models.py` 新增类；`ensure_columns` 会自动补列（只加不删） |
| 改数据源（MySQL→PG） | 只改 `.env` 的 `DATABASE_URL`，代码无需动 |
| 加一个前端页面/面板 | `components/panels/`，入口挂到 `AppSidebar` |
| 调主题/配色 | `styles/appearance.ts` + `styles/global.css` 的 CSS 变量 |
